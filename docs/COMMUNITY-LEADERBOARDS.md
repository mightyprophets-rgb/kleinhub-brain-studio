# Community, Evidence Leaderboards, and Rewards

## Why this exists

The community is not a popularity feed. It is a shared evidence layer for better AI work.

Users can publish:
- Skills
- Prompts
- Skill packs
- Prompt variants

Other users can add them to a Brain, use them with any AI, bring results back, and mark the outcome:
- Worked
- Partly
- Failed

That evidence improves:
1. the community ranking,
2. the creator's feedback,
3. the Lab,
4. Smart Match recommendations.

## Evidence model

Each public Skill/Prompt may track:
- total uses
- unique users
- Worked count
- Partly count
- Failed count
- no-feedback count
- repeat-use rate
- Lab test count
- Lab confidence
- strongest task categories
- strongest model matches
- version
- creator

Popularity metrics such as likes/saves/follows are useful, but stay separate from performance evidence.

## Ranking rules

Leaderboards must be:
- sample-size-aware
- resistant to duplicate/self-voting
- weighted toward verified unique usage
- able to discount suspicious behavior
- version-aware
- transparent enough to explain why something ranked highly

A tiny 100% sample should not automatically beat a large, strong result history.

## Challenges and rewards

Start non-cash:
- badges
- featured placement
- free Member/Pro time
- Lab credits
- provider credits

Later:
- sponsored provider challenges
- cash prizes
- creator revenue share
- premium Skill packs

Example:

Weekly Challenge:
"Build the best Skill for turning messy meeting notes into an action plan."

The winner is selected from evidence, not raw likes alone.

## Guardian + Shield boundaries

Community content is untrusted by default.

Guardian protects:
- user isolation
- permissions
- prompt-injection boundaries
- Brain authority
- private data

Shield protects:
- truth promotion
- evidence quality
- version integrity
- suspicious ranking activity
- confidence labels

A community Skill may help perform a task. It may never silently override confirmed Brain rules or promote suggested knowledge into confirmed/verified truth.

## Lab flywheel

Community Skill/Prompt
-> real usage
-> Worked / Partly / Failed
-> anonymized evidence
-> Lab
-> model/task/prompt/skill performance
-> Smart Match
-> creator feedback
-> improved version

This loop is a core product advantage, not a cosmetic social feature.
